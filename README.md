Statistik Indonesia — a national statistics portal for Indonesia, built for the make.fun "best national statistics site" bounty. Real figures with source and year (BPS / Statistics Indonesia and the World Bank, 2015–2024): population, GDP, inflation, unemployment, poverty, human development, and all 38 provinces. Six working sections (Beranda, Ekonomi, Penduduk, Kesehatan & Pendidikan, Provinsi, Sumber & Metodologi), hand-drawn SVG charts, searchable/sortable province explorer with CSV export. Runs fully offline from static files, on desktop and phone; no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
